# ❤️ Heart Disease Prediction System

A Machine Learning-based web application built using **Python and Streamlit** to predict the likelihood of heart disease based on user-provided medical attributes.

The application provides an interactive interface where users can enter health-related information and receive a prediction generated by a trained Machine Learning model.

## 🚀 Project Overview

Heart disease is one of the major health concerns worldwide. Early identification of potential risk factors can encourage individuals to seek timely medical attention.

This project uses Machine Learning classification techniques to analyze selected health parameters and predict whether the input data indicates a potential presence of heart disease.

The application is developed with Streamlit to provide a simple, interactive, and user-friendly experience.

## ✨ Features

- **Interactive User Interface:** Simple and user-friendly interface developed with Streamlit.
- **Machine Learning Prediction:** Uses a trained classification model to generate predictions.
- **Health Parameter Input:** Accepts relevant medical attributes such as age, cholesterol, blood pressure, and other features used by the model.
- **Instant Prediction:** Displays the model's prediction after submitting the input.
- **Data Visualization:** Supports graphical representation of relevant health data, if included in the application.
- **Web Deployment:** Can be deployed using Streamlit Community Cloud.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https:https://github.com/AdityaTiwari-tech/Heart-Diease-Prediction.git
```

### 2. Navigate to the Project Directory

```bash
cd Heart-Disease-Prediction
```

### 3. Create a Virtual Environment (Optional)

```bash
python -m venv venv
```

Activate the environment:

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the Streamlit Application

```bash
streamlit run app.py
```

The application will open in your browser at:

```text
http://localhost:8501
```

## 🧠 Machine Learning Workflow

The project follows a typical Machine Learning workflow:

1. **Data Collection:** Load the heart disease dataset.
2. **Data Preprocessing:** Handle missing values, prepare features, and perform necessary transformations.
3. **Exploratory Data Analysis:** Analyze patterns and relationships among health attributes.
4. **Feature Selection:** Identify relevant features for model training.
5. **Model Training:** Train a suitable classification algorithm.
6. **Model Evaluation:** Evaluate performance using appropriate classification metrics.
7. **Model Serialization:** Save the trained model for future predictions.
8. **Deployment:** Integrate the model with Streamlit and deploy the application.

## 📊 Prediction Output

The application generates one of the following outputs based on the trained model:

- **Positive Prediction:** The model predicts a potential indication of heart disease.
- **Negative Prediction:** The model does not predict an indication of heart disease.

The prediction depends on the input parameters and the performance of the trained model.

## 🌐 Deployment

This application can be deployed using **Streamlit Community Cloud**.

1. Upload the project files to a GitHub repository.
2. Visit (https://share.streamlit.io/)
3. Connect your GitHub account.
4. Select your project repository.
5. Set the main application file to `app.py`.
6. Click Deploy.

Once deployment is successful, Streamlit will provide a public URL to access your application.
